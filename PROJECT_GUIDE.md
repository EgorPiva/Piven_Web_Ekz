# Полная инструкция по проекту

## 1. Что это за проект

Это экзаменационный Flask-проект "Электронная библиотека".  
Вариант - **4**, функциональность **учета истории посещений**.

Проект показывает:

- каталог книг;
- страницу просмотра одной книги;
- вход в систему;
- роли пользователей;
- учет просмотров книг;
- блок "Популярные книги";
- блок "Недавно просмотренные книги";
- административную статистику;
- экспорт в CSV.

Это веб-приложение электронной библиотеки на Flask. В проекте реализованы роли пользователей, карточки книг, отзывы, а для моего варианта 4 добавлен учет посещений страниц книг. На главной странице есть популярные и недавно просмотренные книги, а у администратора есть отдельная страница статистики с журналом действий и экспортом в CSV.

## 2. Роли и доступ

В проекте есть 3 роли:

- `admin` - полный доступ;
- `moderator` - может редактировать книги;
- `user` - может оставлять отзывы.

Неавторизованный пользователь может:

- открыть главную страницу;
- открыть страницу входа;
- открыть страницу просмотра книги.

Если он попытается зайти в недоступный раздел, его перенаправит на вход с сообщением об авторизации.

## 3. Что реализовано по варианту 4

### 3.1 Популярные книги

На главной странице есть раздел **"Популярные книги"**.

Там отображаются 5 книг, которые чаще всего просматривали за последние 3 месяца.

Что важно:

- учитываются просмотры страниц книг;
- данные обновляются автоматически;
- у каждой книги есть ссылка на страницу просмотра;
- раздел скрыт, если данных пока нет.

### 3.2 Недавно просмотренные книги

На главной странице есть раздел **"Недавно просмотренные книги"**.

Он показывает 5 последних разных книг, которые смотрел текущий пользователь.

Что важно:

- работает и для авторизованного пользователя;
- работает и для неавторизованного пользователя;
- книги идут в обратном хронологическом порядке;
- раздел скрыт, если пользователь еще ничего не смотрел.

### 3.3 Учет просмотров

Каждый открытый просмотр книги записывается в таблицу `book_visits`.

Особенности:

- для авторизованного пользователя сохраняется `user_id`;
- для неавторизованного пользователя сохраняется `anonymous_key`;
- один пользователь не может накрутить больше 10 просмотров одной и той же книги за день;
- счетчик обновляется автоматически при каждом открытии страницы книги.

### 3.4 Страница статистики для администратора

У администратора в меню есть пункт **"Статистика"**.

Внутри две вкладки:

- **"Журнал действий пользователей"**;
- **"Статистика просмотра книг"**.

#### Журнал действий пользователей

Показывает таблицу с полями:

- номер записи;
- ФИО пользователя или "Неаутентифицированный пользователь";
- название просмотренной книги;
- дата и время просмотра.

Особенности:

- сортировка по убыванию даты;
- пагинация по 10 записей на страницу;
- экспорт в CSV доступен кнопкой сверху.

#### Статистика просмотра книг

Показывает таблицу с полями:

- номер записи;
- название книги;
- количество просмотров.

Особенности:

- есть фильтр по диапазону дат;
- можно указать только начало или только конец диапазона;
- пагинация по 10 записей;
- экспорт в CSV;
- статистика считается только по просмотрам авторизованных пользователей, как и требовалось в задании.

## 4. Структура страниц

### Главная страница

На главной странице отображаются:

- блок популярных книг;
- блок недавно просмотренных книг;
- таблица всех книг;
- пагинация каталога;
- кнопки действий по ролям.

Для каждой книги в таблице доступны:

- `Просмотр` - всем пользователям;
- `Редактировать` - администратору и модератору;
- `Удалить` - только администратору;
- `Добавить книгу` - только администратору.

### Страница книги

На странице книги отображаются:

- обложка;
- название;
- автор;
- год;
- издательство;
- объем;
- жанры;
- описание;
- отзывы;
- кнопка добавления отзыва;
- кнопки редактирования и удаления по ролям;
- при открытии страницы создается запись посещения.

### Страница входа

На странице входа пользователь может авторизоваться.

После входа отображается:

- его ФИО в правой части шапки;
- кнопка `Выйти`;
- дополнительные разделы меню в зависимости от роли.

## 5. Как запускать проект

### Вариант для SQLite

```powershell
pip install -r requirements.txt
flask --app app.py init-exam
flask --app app.py run
```

После первого запуска инициализации создаются таблицы и стартовые данные.

### Вход администратора

```text
login: admin
password: admin
```

## 6. Как посмотреть проект

Лучший порядок просмотра такой:

1. Открыть главную страницу и посмотреть каталог книг.
2. Блок **"Популярные книги"**.
3. Блок **"Недавно просмотренные книги"**.
4. Открыть страницу любой книги и увидеть, что просмотр автоматически записывается.
5. Войти под `admin`.
6. Открыть пункт **"Статистика"**.
7. Посмотреть вкладку **"Журнал действий пользователей"**.
8. Посмотреть вкладку **"Статистика просмотра книг"**.
9. Применить фильтр по датам.
10. Скачать CSV и посмотреть, что файл формируется.
